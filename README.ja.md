# grid_2fair

[English](README.md) | 日本語

[OEIS A344719](https://oeis.org/A344719) の項を計算する Rust プログラムです。

n×n の格子のいくつかのマスを塗り、塗っていない全てのマスが上下左右でちょうど 2 個の塗ったマスに隣接するようにします。このとき塗るマスの最小個数が a(n) です。

## 結果

OEIS に載っているのは a(1)〜a(15) です（2026-10-04 時点。a(12)〜a(15) は Bert Dobbelaere による）。このプログラムで a(1)〜a(15) を再現し、その先を求めました。

| n | a(n) | 出どころ |
|--:|--:|---|
| 1〜15 | 1, 2, 5, 8, 11, 17, 21, 28, 35, 42, 51, 60, 69, 80, 91 | OEIS（再現） |
| 16 | 102 | このプログラム |
| 17 | 115 | このプログラム |
| 18 | 128 | このプログラム |
| 19 | 141 | このプログラム |
| 20 | 156 以上 | 予算 155 まで解なし（途中） |

各 a(n) は次の 2 点で確かめています。

- 下界から a(n)−1 までのすべての予算で DP が「解なし」を返した。つまり a(n)−1 個では塗れない。
- a(n) 個の解を復元し、全マスの条件を `Board::is_valid` で検証した。

階差は n = 8 以降 7, 7, 7, 9, 9, 9, 11, 11, 11, 13, 13, 13 と、同じ値が 3 回ずつ続いています。

## 使い方

リリースビルドで実行してください。デバッグビルドは桁違いに遅くなります。

```sh
cargo run --release -- 16            # n = 16 を解く
cargo run --release -- 3 --to 18     # n = 3 から 18 まで順に解く
cargo run --release -- 8 --algo dfs  # アルゴリズムを選ぶ（dp | dfs | brute、既定は dp）
```

出力は、予算ごとの判定結果、復元の経過、解の盤面（`#` が塗ったマス）、塗り数、時間です。
n の上限は dp が 30、dfs が 63、brute が 7 です。実用的に解けるのは dp で 19、dfs で 9、brute で 5 までです。

## アルゴリズム

図と計測つきの説明は [docs/algorithm.ja.html](docs/algorithm.ja.html) をブラウザで開いてください。要点は次の通りです。

- 行をビット列で表し、上から 1 行ずつ決める。2 行決まると次の行の大半が強制される（`forced_below`）。
- 状態を「直前の 2 行」とする行単位の DP。予算 B を決めて「B 個以下で塗れるか」を判定し、予算を下界から 1 つずつ上げる。
- 残りの行の下界は、高さ 9 までの帯の最小塗り数（列方向の DP）をつないで作る。
- 左右反転で重なる状態は 1 つにまとめる。
- 表は 2 枚しか持たず、盤面は向きを交互に変える DP で復元する。

## 計測

Core i7-12700F、メモリ 32GB、シングルスレッドでの値です。

| n | 合計時間 | 状態数の最大 | ピークメモリ |
|--:|--:|--:|--:|
| 16 | 0.75 秒 | 3,324,051 | |
| 17 | 15.2 秒 | 54,660,545 | |
| 18 | 19.4 秒 | 63,314,198 | 4.4 GB |
| 19 | 5,792 秒 | 268,439,434 | |

n = 19 は状態の表がメモリに収まりきらず、1 遷移あたりの時間が n = 18 の 100 倍以上になっています。n = 20 以降には、表を小さくする改良が必要です。

## 構成

| ファイル | 役割 |
|---|---|
| `src/dp.rs` | 予算付きの行単位 DP。帯の下界（`strip_min`、`lower_bounds`）、表 2 枚の DP（`forward`）、判定（`search`）、復元（`reconstruct`） |
| `src/dfs.rs` | 最初に作った行単位の DFS。`forced_below` は DP でも使う |
| `src/brute.rs` | 総当たり。答え合わせ用 |
| `src/board.rs` | 盤面と、条件を満たすかの検証 |
| `src/lib.rs` | OEIS の既知の値 |
| `src/main.rs` | コマンドライン |

## テスト

```sh
cargo test
```

総当たり・DFS・DP の答えが互いに、また OEIS の値と一致すること、下界が答えを超えないこと、
答えより 1 小さい予算では解なしになること、左右対称でまとめても判定が変わらないことを確かめます。
